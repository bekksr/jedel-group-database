# Jedel.Group — простой интерфейс с API

## Запуск

Node.js 24 LTS, терминал в `frontend`:

```bash
npm ci
npm start
```

Открыть http://localhost:4200. Backend запускается отдельно по `../backend/README.md` или `../docs/CONNECTION_SETUP.md`.

По умолчанию включён **API-режим без подключения**. В меню **Connection** введите выданный backend-разработчиком токен. Пароль PostgreSQL вводится только при запуске backend, никогда в браузере. `/api` проксируется на `http://127.0.0.1:8000` через `proxy.conf.json`.

Для показа без сервера: **Connection → Open demo**. Демо не включается автоматически при ошибке API. Перезагрузка возвращает отключённый API-режим; токен и демо-изменения стираются. Демо не отправляется в базу.

## Страницы

- Home — краткое описание и количество записей после успешной загрузки.
- Products — поиск, ID, название, категория, цена, складской остаток и переход к заказу.
- Suppliers — поиск, контакты и выбор поставщика для заказа.
- Orders — создание, позиции и количества, даты, суммы, фильтр и смена статуса.
- Register — только проверка формы. Серверного создания аккаунта в архиве нет.
- Connection — необходимое подключение к существующему backend и явный запуск демо.

Белая/серая тема с синим акцентом, без зелёного, графиков, анимаций и затемнения при наведении. Редактирование справочников и аналитические экраны убраны; backend API для них сохранён.

## Роли и запись

Viewer — просмотр; Buyer — создание заказов; Approver — смена статуса; Admin — оба действия. Это общие токены ролей, не персональные аккаунты. Кнопки учитывают возможности из `/api/access/`, окончательное решение всегда принимает сервер.

В API-режиме сумма и сохранённые цены приходят от Django. Склад обновляет backend при подтверждённой доставке; фронт перечитывает записи. Форма блокирует повторное нажатие во время запроса и сохраняет ввод при ошибке валидации. Если запись подтверждена, но перечитывание не удалось, форма закрывается с предупреждением «не отправлять повторно». После неопределённого результата записи дальнейшие изменения заблокированы до успешного обновления.

Поставщики и товары не связаны отдельной таблицей в исходной схеме, поэтому ограничение ассортимента поставщика не выдумано. Остаток относится к нашему складу и не ограничивает объём закупки.

## Регистрация — незавершённое требование

Форма проверяет имя, email, длину пароля и подтверждение. Она явно сообщает, что аккаунт не создан; пароль не сохраняется и не отправляется. В backend нет registration/login endpoints и согласованной схемы персональных аккаунтов. Полную регистрацию нельзя считать выполненной. Общие токены ролей также не равны требованиям «administrator / manager / employees», если преподаватель ожидает именно такие персональные роли: это необходимо согласовать командой.

## Код

- `src/app/pages/` — простые страницы и форма заказа.
- `src/app/app.ts`, `routes.ts` — общий каркас и маршруты.
- `src/app/store.ts`, `models.ts` — короткие экспорты общего слоя данных.
- `src/app/core/data/` — существующий API-адаптер команды, переключение режима, модели, уведомления, демо и тесты.
- `src/environments/` — адрес API без секретов.
- `src/styles.scss` — общие стили и адаптивная раскладка.

Демо-записи сверены по каждому полю с SQL-дампом полного архива. Они не утверждают актуальность живой базы.

```bash
npm run build

```
